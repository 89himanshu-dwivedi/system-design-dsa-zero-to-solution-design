# ⚙️ Complexity Framework

Every solution should answer:

### Time Complexity

```text
O(1)
O(log n)
O(n)
O(n log n)
O(n²)
...
```

### Space Complexity

```text
How much additional memory
does the solution require?
```

The objective is not to blindly optimize everything.

It is to understand:

```text
Performance
    vs
Memory
    vs
Complexity
    vs
Maintainability
```
