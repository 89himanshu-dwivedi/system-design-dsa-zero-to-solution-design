# System Design / DSA: Zero to Solution Design

Hi, I'm **Himanshu Kumar** — Technical Lead & Solution Architect with **8 years** of experience designing enterprise systems.

I work at **CRISIL Ltd, an S&P Global company**, on S&P Global projects.

This repo is my open log covering problem-solving fundamentals through to production solution design: DSA → algorithms → LLD → HLD → written design docs.

---

## What you'll get from here

- Data structures and algorithms with the **approach and the mistake I made**, not just a passing solution
- Problem-solving patterns: two pointers, sliding window, binary search on answer, union-find, topological sort, DP
- Low-level design: SOLID, design patterns, and classics like rate limiter, cache, parking lot
- System design core: scaling, caching, sharding, replication, consistency, queues, CDNs
- High-level case studies: URL shortener, feed, chat, payments, search, streaming
- Solution design documents in a repeatable format — requirements → NFRs → options → trade-offs → rollout

Useful if you're preparing for interviews, or moving from writing code to writing the design doc that others build from.

---

## The two formats I use

**Problem log**
```
Pattern · Approach · Time/Space · Mistake I made · Revisit on
```

**Design doc**
```
Context & goals · Requirements + NFRs · Capacity estimates · High-level design
Deep dives · Trade-offs and rejected alternatives · Failure modes, monitoring, rollout
```
