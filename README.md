# System Design / DSA / Algorithms: Zero to Solution Design

Problem-solving fundamentals through to production-grade solution design.

---

## Roadmap

| Phase | Folder | Focus |
|---|---|---|
| 0 | `00-complexity/` | Big-O, space/time trade-offs, how to reason about cost |
| 1 | `01-data-structures/` | Arrays, strings, hashing, stacks/queues, linked lists, trees, heaps, tries, graphs |
| 2 | `02-algorithms/` | Sorting, searching, recursion, backtracking, greedy, dynamic programming |
| 3 | `03-patterns/` | Two pointers, sliding window, binary search on answer, union-find, topological sort |
| 4 | `04-problem-log/` | Solved problems: approach, complexity, mistakes, retry date |
| 5 | `05-lld-ood/` | SOLID, design patterns, class-level design (parking lot, rate limiter, cache) |
| 6 | `06-system-design-core/` | Scaling, caching, sharding, replication, CAP, consistency, queues, CDNs |
| 7 | `07-hld-case-studies/` | URL shortener, feed, chat, payments, search, streaming, ride-hailing |
| 8 | `08-solution-design/` | Requirements → NFRs → options → trade-offs → decision record → rollout plan |

## Problem log format

```
## <problem name>
- Pattern:
- Approach:
- Time / Space:
- Mistake I made:
- Revisit on:
```

## Design doc format

```
1. Context & goals
2. Functional + non-functional requirements
3. Capacity estimates
4. High-level design + diagram
5. Deep dives (2–3 components)
6. Trade-offs & alternatives rejected
7. Failure modes, monitoring, rollout
```

See [DAILY-WORKFLOW.md](DAILY-WORKFLOW.md) for the exact edit → commit → deploy loop.
